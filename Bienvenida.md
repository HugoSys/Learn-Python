## ¿Cómo usar este repositorio localmente?

Si quieres clonar este repositorio para probar los scripts en tu computadora:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/TU_USUARIO/TU_REPOSITORIO.git
   ```

2. Accede a la carpeta:
   ```bash
   cd TU_REPOSITORIO
   ```

3. Crea un entorno virtual:
   ```bash
   python -m venv venv
   ```

4. Activa el entorno virtual y aplica dependencias (si aplica):
   ```bash
   # En Windows:
   venv\Scripts\activate
   # En Linux/Mac:
   source venv/bin/activate
   ```
